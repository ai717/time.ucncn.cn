常见问题与操作指南 (FAQ)

如何在会议室大屏、教室投影或电视机上全屏展示？

在任意电脑、平板或智能电视浏览器中打开本站，点击右上角「全屏」图标或在屏幕任意空白区域双击（快捷键 F），即可立即进入零浏览器边框的沉浸全屏状态。若配合点击「巨幕」按钮，数字尺寸将进一步等比放大，数十米外依然清晰可辨。

为什么不需要下载客户端就能长久防息屏常亮？

本站调用了 HTML5 最新的标准 navigator.wakeLock API。只要保持当前浏览器标签页处于前台活跃状态，即可在 iOS Safari、Android Chrome、macOS 及 Windows 上自动锁定屏幕常亮，无需在系统设置中费力关闭自动睡眠锁屏。

倒计时的引线火花炸弹与流沙漏斗各自适合什么场景？

火花引线炸弹以极具戏剧性的盘旋长引线慢慢燃烧到炸弹中心，适合游戏对抗、限时竞速、团队站会汇报等具有紧迫感的游戏化场景；流沙漏斗以高硼硅玻璃曲线和动态堆积的平滑沙丘展现时间的流逝，适合白领办公、自习阅读、瑜伽冥想与禅意生活。

计时声音会消耗手机或电脑的网络流量吗？

完全不会！网站摒弃了一切体积庞大的音频文件加载，全套声音（经典机械发条、石英脉冲、复古落地钟摆、精密秒表齿轮音、黑火药引线滋滋燃烧音与细沙滑落微响）100% 由浏览器底层的 Web Audio API 算法根据物理声学特性实时数学合成，零流量消耗，断网离线亦能秒级发出悦耳声响。
