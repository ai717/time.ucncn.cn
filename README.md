# ⏳ 专注时钟 & 倒计时 (Focus Clock & Countdown)

> **域名**：[time.ucncn.cn](https://time.ucncn.cn)  
> **Slogan**：让工位静下来，让时间看得见。  
> **核心卖点**：四大拟物视觉形态（3D机械翻牌/扫秒大表盘/晶莹流沙/火花炸弹）、沉浸白噪音、原生防息屏常亮、高停留时长专注空间。  
> **归属模式**：独立二级域名项目（模式 A，与 ucncn.cn 主站解耦，主站 Git 已通过 `.gitignore` 排除本目录）

---

## 📖 项目文档

* **完整产品需求说明书 (PRD)**：详见 [PRD.md](PRD.md)
* **核心功能矩阵**：
  1. **3D 拟物机械翻页**：时、分、秒丝滑翻折，支持 12/24 小时制；
  2. **三大模式**：实时时钟、25 分钟番茄专注、正向自习计时；
  3. **防息屏黑科技**：调用浏览器原生 Screen Wake Lock API，手机/iPad 支架常亮不黑屏；
  4. **沉浸白噪音**：雨声、壁炉、咖啡馆、钟摆滴答声自由混音；
  5. **三套高阶美学配色**：OLED 纯黑、羊皮纸白、暖橘微光。
